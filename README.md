## About

I build **local-first AI systems** and **low-level Android tooling**. Most of my work sits at the boundary between a model and the machine it runs on: agent runtimes that keep state across sessions, inference stacks tuned for consumer GPUs, and Android system tools that need root to do anything interesting.

- 🧠 **Autonomous agents** — [Aria-V12](https://github.com/GamerX3560/Aria-V12) is a local-first agentic OS for Linux: a persistent Memory Tree, an executive planning layer, 7 specialist personas, and native Gmail + GitHub integrations. Runs entirely on one AMD RX 6600 (8 GB VRAM) via Ollama + ROCm.
- 📱 **Android internals** — Magisk modules, performance governors and device managers for rooted devices, written in Kotlin with Jetpack Compose front-ends.
- 🐧 **Linux systems** — a full Arch environment that runs on Android hardware, plus the shell tooling to keep it reproducible.
- 🎯 **Working on now** — expanding Aria's self-improvement daemon and shipping on-device inference in [GamerX-AI](https://github.com/GamerX3560/GamerX-AI).
